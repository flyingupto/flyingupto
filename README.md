### 👨‍🔬 About Me

I am a Master's student in **Mathematics (Image and Graphics Processing)** at USTB, expected to graduate in **July 2027**. My research sits at the intersection of **optimization** and **AI**:

- 🧮 **Non-convex & non-smooth optimization** — splitting algorithms, Moreau-envelope smoothing, sparsity-penalized quantile regression
- 🎲 **Bayesian computation & sampling** — MCMC, subspace splitting Gibbs sampling, sampling–optimization duality
- 🖼️ **Inverse problems** — image restoration under nonsmooth heavy-tailed Bayesian priors
- 🤖 **Multimodal AI agents** — tool-augmented vision-language agents + reinforcement learning (SFT & GRPO, QLoRA) for industrial defect detection

🔭 **I am actively seeking a Ph.D. opportunity in Optimization & AI (starting Fall 2027).** I enjoy turning hard optimization problems into provably convergent, practical algorithms — and I would be glad to collaborate or chat. Feel free to reach out!

### 🚀 Featured Projects

| Project | Description |
| :------ | :---------- |
| [**AgentIAD-steel**](https://github.com/flyingupto/AgentIAD-steel) | Tool-augmented single-agent framework for **steel surface defect inspection**. Built on Qwen2.5-VL with a perceptive zoomer + comparative retriever, trained with **SFT → GRPO** and optimized with **4-bit quantization + QLoRA** so it runs on consumer-grade hardware. |
| [**SSGS**](https://github.com/flyingupto/SSGS) | **Subspace Splitting Gibbs Sampling** for high-dimensional image inverse problems — official code & data for the *Inverse Problems* manuscript. Accelerates posterior sampling while preserving geometric ergodicity. |
| [**DMOSH**](https://github.com/flyingupto/DMOSH) | **Dual-metric Optimization-Sampling Hybrid** algorithm for nonsmooth nonconvex composite optimization — code for the *JOTA* manuscript. Uses sampling to escape local optima with a proven convergence guarantee. |
| [**subspace**](https://github.com/flyingupto/subspace) | MATLAB implementation of **Bayesian subspace Gibbs sampling** for high-dimensional linear inverse problems (variable selection & image inverse problems) under nonsmooth heavy-tailed priors. |
